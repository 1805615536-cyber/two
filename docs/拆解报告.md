# 批量剪辑工具拆解与「切影工坊」说明

> v3（2026-11-02）：依据《AI 素材双轨并行路线图》（项目A：AI 混剪+前贴 → AI 换元素 → 脚本仿写）完成能力升级，见文末「v3 新增」。

## 一、录屏工具拆解（OpenFilm Studio）

录屏演示的是一款跑在本机（127.0.0.1:4847）的网页版视频批量生产工具，面向保险口播类短视频的工厂化生产。

**页面结构**
- 左侧导航：自动剪辑 / 审核队列 / 项目空间 / 公用资产库 / 用户管理 / 操作记录 / 设置
- 主页面「自动剪辑」：任务队列表格（任务/脚本、项目/类型、状态与进度、当前环节/异常、编号、创建时间、操作），带状态页签（全部/制作中/待审核/待修改/需处理）、搜索、批量重试、项目设置

**核心流水线**（每个任务按阶段推进，表格里实时显示进度条 + 百分比 + 预计剩余时间）
1. 提交：剧本 + BGM 风格 + 实拍素材 + 交付命名信息（产品名/前贴类型/视频类型/剧本编号/编号/剪辑/摄像/日期等）
2. 自动剪辑：匹配脚本/切气口 → 识别与对齐词 → 命名与导出（组织标准化 720×1280 MP4）
3. 人工审核：任务详情弹窗内嵌成片预览，按钮为 进入剪辑器 / 修改后重新成片 / 审核通过 / 退回修改 / 下载 MP4
4. 交付：按模板自动命名（如 意外守护保-LIVE001-复盘1030）

**可借鉴的设计**：任务队列化（提交后后台跑，页面可关）、进度可视（百分比 + ETA + 环节名）、人工审核关卡（通过/退回）、命名规范化、失败可批量重试。

## 二、新工具「切影工坊 BatchCut Studio」

位置：`batchcut/`，纯 Python 标准库 + 自带 ffmpeg，无需安装任何依赖。

```
batchcut/
├─ backend.py        # 后端：HTTP 服务 + 任务队列 + ffmpeg 指令编译
├─ web/index.html    # 前端：单页应用（无外部依赖，离线可用）
├─ tools/ffmpeg.exe  # 内置 ffmpeg（libx264 / aac / drawtext 可用）
├─ data/             # state.json 任务状态持久化 + uploads/ + output/
└─ start.bat         # 双击启动并打开浏览器
```

**使用**：双击 `start.bat`（或 `python backend.py 8971`）→ 浏览器打开 http://127.0.0.1:8971

**功能对照原工具（v2 已对齐侧边栏）**
| 原工具模块 | 切影工坊实现 |
|---|---|
| 自动剪辑 | 批量建任务（文件夹导入/拖拽上传）+ 全参数剪辑 + 队列进度/ETA |
| 审核队列 | 成片网页预览、审核通过 / 退回重剪 / 下载 MP4 |
| 项目空间 | 项目卡片：任务数/已通过/进行中统计，项目沉淀默认命名规则，建任务自动带出 |
| 公用资产库 | 配乐/水印/素材入库一次全任务复用，支持试听与缩略预览 |
| 用户管理 | 成员 + 角色（管理员/剪辑师/审核员/客户），侧边栏切换当前身份 |
| 操作记录 | 全量操作日志（谁、何时、做了什么），支持搜索 |
| 设置 | ffmpeg 路径检测、字幕字体、并发数、编码预设 |

**剪辑参数**：去片头片尾、倍速 0.25–4×、镜像、旋转 90/180/270、四边裁切、亮度/对比度/饱和度、标题字幕（支持中文）、图片水印（位置/大小/透明度）、BGM 循环混音、输出尺寸预设、CRF；命名模板 `{产品}-{编号}-{序号}-{原名}-{日期}-{剪辑}`；状态 JSON 持久化（重启续跑）。

**回归记录（v2）**：建用户/项目/素材入库 → 建任务（带项目与执行人，命名 `意外守护保-001-001-20261101.mp4`）→ 出片进审核 → 审核员通过 → 操作记录完整落盘（创建任务/素材入库/新建项目/新增用户/审核通过 均记录到人）。

**已知边界**：目前不含语音识别对齐与 AI 剪辑（原工具依赖云端 ASR）；审核「退回重剪」沿用原参数，改参数需新建任务；仅本机访问（127.0.0.1）。

## 三、v3 新增（对齐 AI 素材双轨路线图·项目 A）

| 路线图能力 | 软件落地 |
|---|---|
| AI 混剪能力（已实现） | 新建任务「AI 混剪」模式：选一批原生素材 → 设定条数与每条时长 → 自动随机分段（2.5–6.5s）+ 乱序重组，一稿出 N 条成片 |
| AI 前贴 | 资产库新增「片头/贴片」类型；片头/片尾自动拼接（精剪与混剪均支持），贴片原样置于首尾 |
| AI 换元素（进行中） | 每条混剪自动随机化：镜像 / 边缘裁切 / 微变速 0.95–1.18× / 调色预设 / 标题文案（标题库随机）/ 标题样式（黑条·黄字·投影·描边）/ 水印位置 / BGM（多选随机）→ 一稿多版差异化，规避相似素材审核 |
| 素材库（视频+脚本） | 资产库新增「原生素材」类型，可录入口播脚本/备注；混剪建任务直接选用 |
| 任务管理配套 | 任务列表新增类型筛选（精剪/AI混剪）与混剪标识 |

**技术实现**：所有任务在创建时统一编译为「片段序列」（每段 = 素材+起点+时长），执行引擎统一走「逐段归一化 → concat → 调色/变速/标题 → 水印 → 配乐混音」单次转码流水线；无音轨素材自动补静音；素材探测带缓存。

**真实素材验证**：用 2940×1912 口播录屏 raw.mp4 实测混剪 2 条（12.3s / 12.8s，720×1280）：标题文案、样式、分段画面、裁切、调色全部不同，符合去重预期。

## 四、v4 优化（质检 + 体验修复）

**修复的 bug（都经过实测验证）**
| 问题 | 影响 | 修复 |
|---|---|---|
| 镜像/旋转/裁切参数静默失效 | v3 重写滤镜链时丢失，前端勾了镜像实际没镜像，直接影响换元素去重 | 段内预处理接入 crop→rotate，后处理接入 hflip；旋转 90/270 时 source 尺寸自动宽高互换 |
| 横屏转竖屏只有黑边 | 观感差、平台限流风险 | 新增「填充方式」：模糊背景填充（默认）/ 裁切填满 / 黑边，三种可选 |
| 批量审核条不可用 | 勾选任务时 JS 报错，批量通过/退回/删除全部点不了 | 补上缺失的 syncSelbar 实现 |
| 滑块数值不联动 | 亮度/对比度/CRF 拖动时数字不变 | 全部滑块实时联动显示 |
| 搜索框输入被打断 | 每 1.5 秒轮询重建表格导致输入框失焦 | 数据指纹比对 + 增量刷新（只换表格不动工具栏） |
| 修改并发需重启 | 调大并发不生效 | 工作线程每 2 秒按设置自动伸缩 |
| 模糊填充输出变小 | 首版 overlay 以缩小后的背景为主输入，成片只有 1/8 尺寸 | 背景放大回画布尺寸后再 overlay |

**新增功能**
- **批量打包下载**：勾选多条任务 → 底部「打包下载」→ 服务端打 zip（重名自动加序号、含项目名前缀），写操作记录
- **复制参数新建**：任务详情一键复制该任务的全部剪辑参数到新建表单，改素材不改编排
- 任务详情显示填充方式；参数标签显示「裁切填满/黑边」

**验证记录**：带位置标记的测试素材实测——镜像后文字左右翻转并移位 ✓；12% 四边裁切生效 ✓；旋转 90° 输出 640×480（宽高互换）✓；横屏 1280×720 → 720×1280 模糊填充无黑边 ✓；zip 打包 4 条成片校验完整 ✓；并发改 4 即时生效 ✓。
